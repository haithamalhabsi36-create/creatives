# Creative Industry — الصناعة الإبداعية
 
> Bilingual (Arabic/English) corporate website for **Creative Industry**, an Omani company specializing in manufacturing solutions, plastic products, and industrial packaging.
 
🌐 **Live Demo:** [creative-industry-55mg.vercel.app](https://creative-industry-55mg.vercel.app)
 
---
 
## About the Project
 
Creative Industry is an Omani-managed factory with a specialized team of experienced Omani engineers. The company provides industrial production lines and plastic products for brands and factories, contributing to Oman's economic development and industrial advancement goals.
 
This website serves as the company's digital presence — showcasing its services, products, vision, and contact information — in both **Arabic** and **English**, with full RTL support for Arabic.
 
---
 
## Features
 
- 🌍 **Bilingual Support** — Full Arabic (RTL) and English (LTR) toggle
- 🌙 **Dark / Light Mode** — Theme switcher built in
- 📱 **Fully Responsive** — Optimized for all screen sizes
- ✨ **Smooth Animations** — Powered by Framer Motion and GSAP
- 📬 **Contact Form** — Email sending via Nodemailer
- 🎥 **3D Elements** — Three.js integration for visual effects
- ⚡ **Fast Performance** — Built with Next.js 14 App Router
- 🚀 **Deployed on Vercel**

## Getting Started
 
### Prerequisites
 
- Node.js **18.x** or higher
- npm or yarn
### Installation
 
```bash
# 1. Clone the repository
git clone https://github.com/Aysha-Kassem/Creative-Industry.git
cd Creative-Industry
 
# 2. Install dependencies
npm install
 
# 3. Run the development server
npm run dev
```
 
Open [http://localhost:3000](http://localhost:3000) in your browser.
 
### Available Scripts
 
| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Deployment
 
This project is deployed on **Vercel**. To deploy your own instance:
 
1. Push your code to GitHub
2. Import the repository at [vercel.com](https://vercel.com)
3. Vercel will auto-detect Next.js and configure the build settings
4. Add any required environment variables (e.g., email credentials for Nodemailer)
